# Learning Journal

PMP更新学習の公開用記録。学習実績の正本は非公開のGoogleスプレッドシートです。

## 現在の状態

- [x] 学習実績を集計するPythonスクリプト
- [x] 日次実行するGitHub Actions（22:30 JST）
- [x] README・日別ログ・JSONの生成処理
- [ ] Google認証情報の設定
- [ ] 初回実行・動作確認

**認証情報を設定するまでは、自動更新は稼働しません。**

設定方法は [セットアップ手順](docs/setup.md) を参照してください。

## 公開する情報

講座別・全体の完了件数、進捗率、学習日ごとの完了件数のみ。個別のレッスン名、カレンダー内容、認証情報は公開しません。

## 運用

毎日22:30 JSTに集計し、実績に変更がある場合だけコミットします。GitHubの草はコミット日等の集計条件に従います。
